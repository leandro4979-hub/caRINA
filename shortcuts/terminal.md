# Terminal shortcuts

## Clear the screen

Press `Control-L`.

Redraws the current terminal view without deleting command history.

## Move to line start

Press `Control-A`.

Moves the shell cursor to the beginning of the current command.

## Move to line end

Press `Control-E`.

Moves the shell cursor to the end of the current command.

## Delete the previous word

Press `Option-Delete`.

Removes the word immediately before the shell cursor.

## Search command history

Press `Control-R`, type a query, then press `Return`.

Finds and runs a previous matching shell command.
